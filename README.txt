CARP FISHING MOBILE APP (PWA)

Preview: extract the ZIP and open index.html.

To install with full offline support, upload the extracted folder to an HTTPS host such as GitHub Pages, Netlify or Cloudflare Pages.
Android Chrome: open the hosted URL > menu > Install app.
iPhone Safari: open the hosted URL > Share > Add to Home Screen.

Your text is stored locally in the browser. Use Export JSON regularly. Photo selection is temporary.
